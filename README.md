# 🌐 HTML & CSS Course - Beginner to Pro

Repositório com o código-fonte, exercícios práticos e pequenos componentes desenvolvidos durante o curso completo de **HTML & CSS** do canal **[SuperSimpleDev](https://www.youtube.com/@supersimpledev)**.

---

## 📌 Sobre o Repositório

Este repositório serve como um registro do meu aprendizado contínuo nos fundamentos do desenvolvimento web front-end. Todo o código foi escrito utilizando o **Visual Studio Code (VS Code)**, abordando desde a estruturação básica com tags HTML5 até técnicas modernas de estilização CSS.

---

## 🚀 Conteúdo & Exercícios Desenvolvidos

- **Estruturação HTML5:** Semântica básica, parágrafos, cabeçalhos, links, imagens e botões.
- **Estilização CSS:**
  - Manipulação de fontes (integração com Google Fonts).
  - Cores, bordas, sombras (`box-shadow`) e arredondamento (`border-radius`).
  - Efeitos de hover, transições e estados interativos (`:hover`, `:active`).
- **Modelo de Caixa (Box Model):** Margin, padding, tamanho de elementos e bordas.
- **Layout & Posicionamento:** Alinhamentos, estruturas de grid/flexbox e conceitos de posicionamento na página.
- **Componentes Práticos:** Recriação de botões estilizados (ex: estilos da Amazon, YouTube, Twitter), cards de produtos e páginas promocionais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Linguagem de Marcação)
- **CSS3** (Estilização de Páginas e Componentes)
- **Visual Studio Code** (Editor de Código / Ambiente de Desenvolvimento)
